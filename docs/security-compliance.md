# 보안 준수 기록: EDUCONNECT

## 1. 기준

정책 원문 미확보. 아래 항목은 온보딩 안내의 요약(SEC-01~12)이며 원문이 아니다. 주최 측 보안 기준 원문을 받으면 항목 ID·이름을 원문 그대로 바꾸고 판정을 다시 한다. 없는 정책을 만들어 내거나 필요 없는 인증 기능을 요구하지 않는다.

- 입력: docs/intent.md 12장(2026-10-10 확정), docs/prd.md 8절 보안 매핑과 4.2 확인 조건(status final, 커밋 632c93f).
- 작성 시점 상태: 제품 코드 없음. 구현 코드 칸은 arch 확정 뒤 경로를 적는다. 시험 칸의 TC ID는 e2e-doc 계획 단계에서 채우며, 지금은 근거가 되는 확인 조건(AC)을 적는다. 성공·거부 결과 칸은 관찰값이 아니라 **기대값**이다.
- 모든 판정은 실행 근거가 없으므로 `미검증`이다.
