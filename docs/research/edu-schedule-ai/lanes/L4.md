# L4 기술·API·오픈소스

## 결론
- 학교 기본정보·학원교습소정보(교습과정·수강료 일부)는 NEIS 개방 포털 OpenAPI로 무료 연동 가능하다. 인증키는 즉시 발급이고, 키 없이도 5건 샘플은 받는다.
- NEIS 시간표는 학교 정규 수업 시간표이고, 두 데이터셋 모두 샘플 행에서 위경도가 보이지 않는다. 이동시간은 주소 지오코딩 후 하버사인 근사가 현실적이다.
- 일정 최적화는 OR-Tools CP-SAT(정수 모델), LLM은 설명·후보 생성 보조에 두고 검증은 규칙/솔버가 맡는 구성이 근거와 맞는다.

## 사실
- Q10 학교기본정보: 학교명·소재지·주소·전화번호·홈페이지·공학여부·주야구분·개교기념일 제공, 이용허락 제한 없음 [L4-01]. 샘플 응답에도 도로명주소·전화번호 필드가 있으나 위경도 필드는 보이지 않는다 [L4-11].
- Q10 인증: OpenAPI는 인증키 필요, 포털 회원 인증으로 로그인해 신청하면 즉시 발급 [L4-02]. 키 없으면 5건 샘플만 출력 [L4-03].
- Q10 승인·한도: 공공데이터포털에는 개발단계 자동승인/운영단계 심의승인, 트래픽은 기관 정책에 따라 상이로만 표시된다 [L4-06, L4-07].
- Q10 시간표: 초등학교 시간표는 학년도·학교·학기·학년·학급·교시별 시간표와 수업내용(학교 정규 수업)을 제공, 적재 주기 매일 [L4-04]. 2023학년도 8월~2024학년도 구간은 API 조회 불가 [L4-05].
- Q11 학원교습소: 학원명·휴원일자·등록상태·정원·분야·계열·과정 제공, 수강료는 공개 여부에 따라 [L4-08, L4-12]. 서울 샘플에서 과정별 교습비 문자열과 도로명주소가 확인되나 교습비가 빈 행도 있다 [L4-09]. 서울 목록 25,527건 [L4-10]. 이용허락 제한 없음 [L4-08, L4-12].
- Q12 CP-SAT: 정수만으로 모델을 정의해야 한다 [L4-13]. 문서에 제약 충족 일정 예제(직원 일정)가 있다 [L4-14].
- Q12 오픈소스(2026-10-10 조회): google/or-tools Apache-2.0·별 14,167·push 2026-10-09 [L4-15]; Timefold Solver Apache-2.0·별 1,821·push 2026-10-10 [L4-16]; UniTime Apache-2.0·별 350·push 2026-10-09 [L4-17]; python-constraint BSD-2-Clause·별 520·push 2026-10-06 [L4-18].
- Q13: LLM 단독 계획·자기검증의 한계와 외부 검증기 결합(LLM-Modulo) 제안 [L4-19]; 여행 계획 벤치마크에서 GPT-4 성공률 0.6% [L4-20].
- Q14: 카카오 쿼터 문서 일간 쿼터 표에 자동차 길찾기 10,000건(변경 가능) [L4-21]. OSRM 공개 데모 서버는 접근 철회 가능·품질 보장 없음 [L4-22]. OSRM 자체 호스팅용 오픈소스는 BSD-2-Clause [L4-23]. 하버사인은 위경도로 구면 위 두 점의 대원거리를 계산 [L4-24]. 카카오 로컬 API 주소 검색은 주소의 좌표 정보를 제공하며 REST API 키를 헤더에 담아 호출한다(종합 단계 재검색으로 추가) [L4-25]. 같은 쿼터 문서의 무료 일간 쿼터 표에 주소로 좌표 변환 100,000건(변경 가능)이 있다 [L4-26].

## 추론
- 실제 연동 vs 모의: 학교·학원 정보는 실제 NEIS 호출이 가능하나 키가 필요하므로 데모는 키 없는 5건 샘플 또는 저장한 JSON 스냅샷으로 재현할 수 있다 [L4-03, L4-09].
- NEIS 시간표는 학교 수업 시간 중복 확인용이고 학원 수업 시간표는 담지 않는 것으로 보인다. 학원 요일·시간은 확인된 필드에 없어 사용자 입력이나 모의 데이터가 필요하다 [L4-04, L4-09].
- 위경도가 샘플에 없으므로 이동시간은 주소 지오코딩 단계가 추가로 필요하다. 지오코딩 API의 조건은 이번에 확인하지 못했다 [L4-09, L4-11].
- 해커톤 규모에서는 학교·학원 좌표를 사전 입력하고 하버사인 직선거리에 보정 계수를 곱하는 근사로 외부 지도 API 없이 동작 가능하다. 도로 이동시간과 차이가 나므로 근사임을 표시해야 한다 [L4-24].
- LLM 역할 제한: 후보 설명·자연어 요약은 LLM에, 시간 중복·예산·이동 제약 판정은 규칙·솔버에 두는 구성이 [L4-19, L4-20]과 부합한다. API 키 없는 재현은 규칙 기반 가중합 점수화와 템플릿 설명(결정적 대역)으로 대체할 수 있다. 이 대체 방식 자체의 선행 사례는 확인하지 않은 설계 판단이다.
- 시간대 수가 작은 문제라면 CP-SAT 없이 백트래킹·그리디 휴리스틱도 충분할 수 있다(규모 가정이며 근거는 확인하지 않음). CP-SAT는 정수 모델링(분 단위, 원 단위)이 필요하다 [L4-13].

## 미확인
- NEIS OpenAPI의 구체적 호출 제한 횟수: 포털 상세 화면 '신청제한횟수'가 비어 있고 공공데이터포털은 기관 정책에 따라 상이라고만 표시. 확인되지 않음.
- 학원교습소정보 OpenAPI의 전체 출력 필드 명세(명세서 파일)와 학원의 요일·시간 필드 유무: 상세 화면 명세 표가 비어 있고 샘플 1건만 확인. 확인되지 않음.
- NEIS 시간표(중·고) 개별 샘플 응답: 인증키 없는 중학교 호출은 '해당하는 데이터가 없습니다' 응답이어서 필드 확인 못 함.
- 주소 지오코딩(카카오 로컬 등)의 무료 조건과 길찾기 API 사용 권한 신청 여부: 쿼터 페이지에서 확인되지 않음. 네이버 지도·T map 등 다른 사업자 조건은 찾아보지 않음.
- OSRM 현행 데모 서버(FOSSGIS) 이용약관 원문(독일어)과 요청 빈도 제한 수치는 직접 받아 확인하지 않음.
- LLM 키 없는 대체 방식의 선행 연구·오픈소스 사례: 검색하지 않음.
