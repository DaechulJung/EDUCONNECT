# L3 시장·경쟁·유사 서비스

## 결론
- 학원 검색·비교 앱(학원맵, 써치클래스)은 수강료·위치·시간표·리뷰를, 자녀 일정 앱(하원나우, 위클링, 맘편한 일정)은 시간표·알림·학원비 관리를 각각 다룬다. 런즈는 학원 찾기·정보와 가족 공유 스케줄러를 한 앱에서 소개한다(종합 단계 검토로 추가) [L3-14]. 검색 결과로 일정을 자동 구성·최적화하는 서비스는 이번 조사에서 확인되지 않았다.
- 2025년 사교육비 총액 27.5조원, 참여율 75.7%로 시장은 크지만 전년보다 줄었다.

## 사실
- 학원맵은 수업 내용·학원비·셔틀 여부 미리보기를 소개한다(스토어 설명, 개발사 자기소개). [L3-01]
- 학원맵은 재원 인증 리뷰·지도 탐색·북마크·문의 기능을 소개한다. [L3-02]
- 써치클래스는 학원·강의 정보, 위치, 시간표, 설명회를 제공하고 대치동·목동·분당·일산부터 서비스한다(2024년 6월 보도). [L3-03]
- 써치클래스 앱에는 리뷰가 표시되지 않고 카카오톡 상담 기반 강의 추천을 병행한다(보도 시점). [L3-04]
- 하원나우는 학원별 수업 시간·학원비·교사 연락처 관리와 결제 예정일 표시를 소개한다. [L3-05]
- 하원나우는 주간 시간표, 수업·하원·결제일 알림, 월별 학원비 통계, 위젯을 소개한다. [L3-06]
- 위클링은 초등 주간 스케줄, 학원별 지출·월별 통계, 이미지/PDF 공유를 소개한다. [L3-07]
- 맘편한 일정은 등/하원 알림과 학부모·학생 실시간 스케줄 공유를 소개한다. [L3-08]
- 2025년 조사: 총액 27조5000억원(5.7% 감소), 참여율 75.7%, 주당 7.1시간. [L3-09]
- 참여학생 1인당 월평균 60만4000원(+2.0%), 고등학교 79만3000원. [L3-10]
- 전체 학생 1인당 월평균 45만8천원; 초 43만3천·중 46만1천·고 49만9천. [L3-11]
- 참여학생 기준 과목별: 영어 28.1만, 수학 27만, 국어 18.5만, 사회·과학 16.6만원. [L3-12]
- 예체능 수강 목적은 취미·교양·재능 계발이 63.2%. [L3-13]

- 런즈는 맞춤 학원 찾기, 학원 정보(수업내용·학원비·셔틀), 우리집 공유 스케줄러를 한 앱에서 소개한다(스토어 설명). [L3-14]

## 추론
- 일정 앱 3종은 모두 학부모 수동 입력 중심으로 소개돼 있고(스토어 설명 기준) 보호자 간 공유는 이미지 공유 또는 실시간 공유 수준이다. 학원 정보 검색과 일정 자동 연동이 차별화 여지일 수 있다. [L3-05, L3-07, L3-08, L3-03]
- 영어·수학 비중이 커서 일정 관리 대상 학원은 교과 학원이 중심일 가능성이 높다. [L3-12]

## 미확인
- 학년별·예체능의 2025년 금액·비중 수치: 확인되지 않음 — 뉴시스·서울신문·이투데이 기사 확인, 교육부 보도자료 원문·KOSIS 표는 접근하지 않음.
- 앱별 이용자 수·평점·가격(유료 여부): 확인되지 않음(L5 영역). 앱 소개 날짜도 확인하지 않음.
- 학원 검색 앱의 제공 데이터 출처(공공 데이터 연계 여부): 확인되지 않음.
- 통계청 조사표 원문(index.go.kr)은 받았으나 수치 표가 동적 로딩되어 인용하지 않음.
