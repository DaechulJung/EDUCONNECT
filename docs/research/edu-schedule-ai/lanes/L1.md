# L1 제도·법령·공공

## 결론
- 학원 교습비등은 게시·광고 표시·서면 고지·초과징수 금지·반환기준이 법령에 있고(2026-10-01 시행본), 교육감이 교습비등을 시·도교육청 홈페이지에 공개하도록 한다. 목업 스키마에 교습과정·정원·교습기간·총교습시간·교습비·기타경비를 둘 근거가 된다.
- 만 14세 미만 자녀 정보를 받으려면 법정대리인 동의와 동의 확인이 필요하다(개인정보 보호법 제22조의2). 보호자 계정 중심 설계가 맞다.
- 초등 방과후는 2026 늘봄학교 길라잡이 기준으로 맞춤형(무상, 초1~2)과 선택형(돌봄·교육, 수익자 부담)으로 나뉜다.

## 사실
- 교습비등 = 교습비(수강료·이용료·교습료 등) + 기타경비(추가로 납부하는 모든 경비) [L1-01]
- 교습비는 교습내용·교습시간 등을 고려해 정하고 기타경비는 실비로 정한다 [L1-02]
- 교습비등과 반환 사항은 보기 쉬운 장소에 게시해야 하고, 모집 광고 시 교습비등과 증명서 내용 중 대통령령 사항을 표시해야 하며, 요구 시 서면 고지한다 [L1-03]
- 광고 표시 증명서 사항: 등록·신고 번호, 학원·교습소 명칭, 교습과정 또는 교습과목 [L1-05]
- 거짓 표시·고지, 표시·등록 금액 초과 징수 금지 [L1-04]
- 반환사유 4종(학습자 격리, 등록말소 등, 학원 측 교습불능, 본인 의사 수강 포기)과 사유 발생일부터 5일 내 반환 [L1-06]
- 반환기준(1개월 이내 계약, 수강자 귀책 해지): 개시 전 전액, 1/3 경과 전 2/3, 1/2 경과 전 1/2, 1/2 경과 후 없음. 1개월 초과는 해당 월 환급액 + 나머지 월 전액 [L1-07]
- 교육감은 교습비등을 학원 종류별·교습과정별·지역별로 분류해 시·도교육청 홈페이지 등에 공개한다 [L1-08]
- 공개 범위: 명칭, 주소·대표전화, 교습과정, 과목별 정원, 과목별 교습기간·총교습시간, 교습비·기타경비, 설립·운영자·강사 명단, 교습자 명단 [L1-09]
- 충북교육청 안내: 정보공개 개시 2012. 3. 1 [L1-10]
- 나이스 '학원교습소정보'는 교육부·16개 시도교육청 제공, 매주 적재, 이용 허락 범위 제한없음 [L1-11]
- 만 14세 미만 아동 개인정보 처리에 동의가 필요하면 법정대리인 동의를 받고 동의 여부를 확인해야 한다 [L1-12]
- 법정대리인 동의에 필요한 최소 정보(성명·연락처)는 아동에게서 직접 수집 가능하고, 아동 대상 고지는 쉬운 양식·언어로 한다 [L1-13]
- 동의 확인 방법 예: 사이트 동의 표시 후 문자 통지, 카드정보, 휴대전화 본인인증, 서면, 전자우편, 전화 [L1-14]
- 개인정보위 가이드라인(2022. 7.): 14세 미만 동의는 법정대리인 동의를 전제로 효력, 보호 중심 설계로 연령 확인·높은 기본값·위치추적 비활성화·부정사용 방지 권고 [L1-15, L1-16]
- 늘봄학교: 맞춤형(초1~2, 매일 2시간 이상, 무상) / 선택형 돌봄 / 선택형 교육(특기·적성·교과) [L1-17, L1-18]
- 방과후 수강료는 강사료·도서구입비·재료구입비·수용비로 구성되고 인근 사교육기관보다 저렴하게 책정하며, 학교 누리집에 프로그램명·수강료·정원을 공개한다 [L1-19, L1-20]
- 수강료 환불 기준 예시는 학원 기준과 같은 1/3·1/2 구조이고 도서·재료비는 제외 [L1-21]
- 초3 희망 학생 방과후 이용권 1인 50만 원 지원 원칙(시도별 상이) [L1-22]

## 추론
- 목업 학원 데이터에 정원·교습기간·총교습시간·교습비·기타경비·강사명단을 두면 공개 제도 항목과 맞는다 [L1-09, L1-11]
- 환불 시뮬레이션 기능을 넣는다면 1/3·1/2 경과 기준이 학원·방과후 양쪽에 공통이다 [L1-07, L1-21]
- 자녀 프로필은 보호자 동의 후 최소 항목(이름 대신 별칭·학년 등)만 받는 설계가 가이드라인 권고와 맞는다 [L1-12, L1-15, L1-16]
