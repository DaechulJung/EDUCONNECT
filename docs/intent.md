## 1. 결론

- 보호자는 학교·학원·방과후 정보를 따로 확인해 자녀 일정을 짠다. 공개 앱은 대부분 학원 검색(학원맵·써치클래스)과 일정 기록(하원나우·위클링·맘편한 일정)으로 나뉘어 소개되고 [L3-01, L3-03, L3-05, L3-07, L3-08], 런즈는 학원 찾기·정보와 가족 공유 스케줄러를 한 앱에서 소개한다 [L3-14]. 검색 결과로 일정을 자동 구성·최적화하는 기능은 이번 조사에서 확인되지 않았다(찾아본 곳: 앱 스토어 설명·보도).
- 학원 교습비등은 법령상 게시·표시·공개 대상이고 공개 범위에 교습과정·정원·교습기간·총교습시간·교습비·기타경비·강사 명단이 있다 [L1-03, L1-09]. 나이스 개방 포털이 학교기본정보·초등 시간표·학원교습소정보를 제공해 목업 스키마의 현실 근거가 된다 [L4-01, L4-04, L4-08].
- KT '모두의 AI'는 2026-10 클로즈 베타·12월 정식 계획이 보도됐고, 외부 개발자용 공개 API는 이번 조사에서 확인되지 않았다 [L2-04, L2-06].
- 확정: EDUCONNECT는 보호자에게 챗봇으로, 학원·학교에는 웹 입력 화면으로 제공하는 하나의 반응형 웹이다. 목업 학교 2·학원 5곳으로 자녀 학교 일정에 맞춰 영어·수학 위주로 촘촘한 주간 일정과 월 학원비 100만원 전후의 계획을 만든다. LLM은 Azure OpenAI를 쓰고, 일정 판정·최적화는 결정형 엔진이 맡는다.

## 3. 문제

- 겪는 사람과 상황: 자녀 교육계획을 세우는 보호자가 학교·학원·방과후 정보를 개별 확인·비교해야 한다(과제 공지 1장). 초등은 학교급 중 사교육비 총액이 가장 크다(2025년 12조2000억원) [L3-11]. 맞벌이 가정의 이른 하교(사례) [L5-15]와 늘봄학교 외 대안 부족(사례) [L5-14]이 공개 커뮤니티에 보인다.
- 지금 버티는 방법: 일정 앱에 수업 시간·학원비를 직접 입력하거나 [L3-05, L3-07], 엑셀·메모 사진으로 가족과 공유한다(사례 1건) [L5-09]. 학원은 지인 추천에 의존했다는 사례(2020) [L5-10]와 맘카페 광고 혼입으로 후기를 앱에서 찾는다는 사례 [L5-08]가 있다.
- 그대로 두면 드는 비용: 참여학생 1인당 월평균 사교육비 60만4000원(2025, 전년 대비 2.0% 증가) [L3-10] 규모의 지출을 정보 비교 없이 결정하게 된다. 시간·이동 비용의 정량 근거는 확인되지 않음.
- 왜 지금: KT 컨소시엄이 '모두의 AI'를 2026-10 클로즈 베타, 12월 정식 서비스로 계획하고 12월에 교육 등 외부 서비스 연계로 확대할 계획이라고 보도됨 [L2-04]. 2026학년도 초3 희망 학생 방과후 프로그램 이용권(1인 50만 원 지원 원칙, 학교 안 수강료로 사용, 시도별 상이) [L1-22].

## 4. 사용자

### 주 사용자

보호자 — 맞벌이 등으로 하교 후 시간을 직접 챙기기 어려운 보호자 [L5-14, L5-15]. 챗봇에 자녀와 조건(예산·과목·요일·위치)을 말하면 학교 시간표와 학원 프로그램을 종합한 추천·비교와 주간 일정을 받는다. 성공했다고 느끼는 순간: 학교 일정과 겹치지 않고 예산 안에 드는 영어·수학 중심 주간 일정이 한 화면에 나왔을 때 (D-2, 위임).

### 보조 사용자

학원 운영자 — 웹에서 자기 학원의 프로그램(요일·시간, 교습비·기타경비, 강사, 대상 학년, 정원)을 등록·수정한다. 학교 담당자 — 웹에서 정규·방과후 시간표를 입력한다 (D-2, 위임).

### 대상이 아닌 사용자

자녀 본인(계정 없음 — 보호자 계정만 둔다, D-11 위임). 실제 결제·환불을 처리하는 사용자(실결제 제외, D-3 위임).

### 해결하려는 일

- 기능: 학교 일정에 맞춰 학원 프로그램을 고르고 비교해 예산 안의 주간 일정을 만든다. 기관 정보가 바뀌면 영향받는 일정을 알고 조정한다.
- 상황: 퇴근 뒤·이동 중 모바일에서 대화로 조건을 말한다.
- 기관: 자기 기관 정보만 정확히 입력·수정하면 보호자 계획에 반영된다 (D-6, 위임).

## 5. 해결 방향

- 해결 방식: 보호자가 챗봇에 자녀와 조건을 말하면, LLM(Azure OpenAI)이 조건을 구조화해 화면에서 확인·수정하게 하고, 결정형 엔진이 학교 시간표와 학원 프로그램을 종합해 시간 중복·예산·이동시간·밀도를 판정·최적화한 추천과 주간 일정을 만든다. LLM은 대화·조건 추출·추천 이유 설명만 맡는다. 학원·학교 담당자가 웹에서 정보를 바꾸면 영향받는 계획을 표시하고 조정을 제안한다 (D-6·D-7, 위임).
- 차별점: 공개 앱 소개 기준으로 학원 검색(학원맵·써치클래스)과 일정 관리(하원나우·위클링·맘편한 일정)가 대부분 나뉘어 있고, 일정 앱은 보호자의 수동 입력 중심으로 소개된다 [L3-01, L3-03, L3-05, L3-07, L3-08]. 런즈는 학원 찾기와 공유 스케줄러를 함께 소개하지만 [L3-14], 예산·시간 중복·이동 제약으로 일정을 자동 구성하는 기능은 이번 조사에서 확인되지 않았다(찾아본 곳: 앱 스토어 설명·보도, L3 노트).
- MVP의 성격: 문제 해결 — 공지 개발 조건 3의 "AI 추천부터 교육 일정 생성·관리까지 핵심 흐름이 실제로 동작"함을 목업 데이터로 증명한다 (D-3, 위임).
- 이후 방향: 'EDUCONNECT 챗봇 = 모두의 AI 교육 에이전트'로 표현하고, 모두의 AI 플랫폼 연동은 어댑터 경계만 두고 '모의'로 표시한다. 연동 경로가 확인되면 어댑터를 교체한다 (D-8, 위임). '모두의 AI'는 정보를 찾고 비교·추천받은 뒤 실제 서비스 이용으로 연결하는 AI로 소개됐다 [L2-08].

## 7. 사용 장면

### 장면 1. 보호자가 챗봇으로 초5 자녀의 영어·수학 주간 일정을 만든다

- 주인공과 상황: 초5·중1 두 자녀를 둔 맞벌이 보호자(데모 보호자 계정). 평일 저녁, 다음 달 학원 일정을 정해야 한다.
- 시작 상태: 시드 계정으로 로그인한 상태, 모바일 폭. 보호자 홈(챗봇)에서 시작한다.
- 경로: ① 챗봇에 "초5 아이 영어·수학 위주로 월 100만원 전후로 촘촘하게"라고 말한다 → ② 추출된 조건(자녀·과목·예산·요일·위치)을 화면에서 확인·수정한다 → ③ 학교 시간표와 학원 5곳을 종합한 추천 후보를 비교한다(교습비·기타경비·이동 근사·이유) → ④ 주간 일정을 생성하고 수업 하나를 바꾸거나 빼는 수정을 한다 → ⑤ 일정을 확정한다.
- 가치가 전달되는 순간: 학교 시간과 겹치지 않고 이동시간이 확보된 영어·수학 주 2회 이상 일정과 월 학원비 합계(100만원 전후)가 한 화면에 보일 때.
- 끝난 뒤 상태: 확정 일정이 일정 탭에 저장되고, 기관 정보가 바뀌면 영향 표시를 받는다.
- 실패 상황: Azure OpenAI 키가 없거나 오류가 나면 규칙 추출과 템플릿 설명으로 대체되어 흐름이 계속된다. 조건을 모두 만족하는 해가 없으면 어떤 조건을 완화해야 하는지 보여 준다.

### 장면 2. 학원 담당자가 수업 시간·수강료를 바꾸고 영향받는 계획을 본다

- 주인공과 상황: 학원 A 담당자(데모 학원 계정). 다음 달부터 수학 반 시간을 옮기고 교습비를 올린다.
- 시작 상태: 시드 계정으로 로그인, 데스크톱 폭, 기관 사이드바.
- 경로: ① 자기 학원 프로그램 목록을 연다 → ② 요일·시간과 교습비를 수정해 저장한다 → ③ 시스템이 이 프로그램을 쓰는 확정 계획을 찾아 영향(시간 중복·예산 초과·이동 부족)을 표시한다 → ④ 보호자는 일정 화면에서 영향 표시와 조정 제안을 보고 수락·거절한다.
- 가치가 전달되는 순간: 보호자가 자기 계획 중 무엇이 왜 깨졌는지와 대안 일정을 바로 보는 순간.
- 끝난 뒤 상태: 보호자가 조정안을 수락하면 계획이 갱신되고, 거절하면 기존 계획에 경고가 남는다.
- 실패 상황: 학원 A 담당자가 학원 B 프로그램을 수정하려 하면 서버가 거부한다.

### 장면 3. 학교 담당자가 정규·방과후 시간표를 웹으로 입력한다

- 주인공과 상황: 초등학교 담당자(데모 학교 계정). 학기 시간표와 방과후 프로그램을 등록한다.
- 시작 상태: 시드 계정으로 로그인, 데스크톱 폭, 기관 사이드바.
- 경로: ① 학년별 정규 시간표(요일·하교 시각)를 입력한다 → ② 방과후 프로그램(요일·시간·수강료·정원)을 입력한다 → ③ 저장하면 그 학교 자녀의 일정 생성에 반영된다.
- 가치가 전달되는 순간: 보호자 일정 생성이 입력한 하교 시각 이후로만 학원을 배치할 때.
- 끝난 뒤 상태: 시간표가 바뀌면 장면 2와 같은 영향 표시가 생긴다.
- 실패 상황: 같은 학년·요일에 겹치는 시간을 입력하면 저장 전에 오류를 표시한다.

(D-6, 위임) 학교 2곳은 초등 1·중학교 1, 데모 자녀는 학교별 1명씩(초5·중1)이고 핵심 시연은 초5 영어·수학이다.

### 이번 버전에 포함

공지 9항목·개발 조건 4개 전부와 사람이 정한 MVP를 합친다 (D-3, 위임). 결손 ④-1·④-2는 근거가 없을 뿐 필수 범위다.

- 기관 웹 입력·관리: 학원 담당자는 자기 학원 프로그램(요일·시간, 교습비·기타경비 분리, 강사, 대상 학년, 정원, 좌표)을, 학교 담당자는 정규·방과후 시간표를 등록·수정한다. 교과·예체능·기타 과목을 모두 다룬다(공지 ①-2).
- 자녀·조건 관리: 보호자가 챗봇 대화로 자녀(별칭·학년·학교·관심사·교육 목표·기존 일정)와 조건(월 예산, 선호 과목, 학원 유형, 위치, 가능 요일)을 설정한다. 챗봇이 추출한 조건은 구조화되어 화면에서 확인·수정한다.
- AI 추천·비교: 조건에 맞는 프로그램 후보를 교습비·기타경비·이동 근사·추천 이유와 함께 비교한다. 시연의 중심은 영어·수학이다.
- 주간 일정 생성·최적화: 결정형 엔진이 학교 시간표와 학원 프로그램을 종합해 시간 중복·예산·이동시간·밀도를 판정하고 최적화한다. 자녀 학교 일정에 맞춰 영어·수학 위주로 촘촘하게 짜고, 기준 시나리오의 월 학원비는 100만원 전후다.
- 선택·수정(④-1): 추천 결과에서 프로그램을 고르고 빼거나 바꾸면 규칙 검증을 다시 한다.
- 변경 영향·조정(④-2): 기관 정보가 바뀌면 영향받는 계획을 표시하고 조정안을 제안한다.
- 인증·권한: 최소한의 시드 계정 로그인과 서버측 인증·역할·소유권 검사 (D-14, 위임).

- 실제 NEIS·지도 API 호출 — 공지 개발 조건 1이 목업을 요구한다. 데이터 스키마만 공개 항목을 참고한다 (D-3, 위임)
- 리뷰·커뮤니티 — 핵심 흐름과 무관 (D-3, 위임)

## 12. 제약

- 법령·제도: 학원 교습비등 게시·표시·초과징수 금지·반환기준 [L1-03, L1-04, L1-06]. 표시 범위는 10장. 학원 프로그램 화면은 교습비와 기타경비를 분리해 표시한다 (D-9·D-11, 위임). 실결제·환불 처리는 하지 않는다.
- 개인정보: 만 14세 미만 법정대리인 동의·확인 [L1-12, L1-14]. 개인정보위 가이드라인(2022. 7. 판, 이후 개정 미확인)은 연령 확인, 높은 기본값, 위치추적 비활성화를 권고 [L1-15, L1-16]. 보호자 계정만 두고, 자녀는 별칭·학년·관심사 등 최소 항목만 저장한다. 14세 미만 법정대리인 동의 확인은 모의 체크 단계로 둔다. Azure OpenAI로 보내는 정보는 별칭·학년·관심사·조건만이고 실명·연락처 같은 식별정보는 보내지 않는다 (D-11, 위임). Azure OpenAI 설정값은 환경변수로만 두고 외부에 노출하지 않으며 AI 호출 내용에도 포함하지 않는다(사용자 결정).
- 접근성 수준: WCAG 2.2 AA 목표 (D-12, 위임).
- 표시 의무 문구: 학원 정보 광고 시 등록·신고 번호·명칭·교습과정 표시 의무 [L1-05]. 서비스는 학원 광고가 아니므로 표시 의무를 그대로 지지 않되, 학원 정보 화면에 명칭·교습과정·교습비·기타경비를 분리 표시한다 (D-11, 위임).

## 20. 핵심 사실

### L1 제도·법령·공공

- 교육감은 교습비등을 학원 종류별·교습과정별·지역별로 분류해 시·도교육청 홈페이지 등에 공개한다 [L1-08]. 충북교육청 안내상 정보공개 개시일 2012. 3. 1 [L1-10].
- 법정대리인 동의 확인 방법에 문자 통지, 카드정보, 휴대전화 본인인증, 서면, 전자우편, 전화 등이 있다 [L1-14].
- 선택형 교육 프로그램은 정규수업 외 시간의 특기·적성·교과 프로그램이고, 학교는 프로그램명·수강료·정원을 누리집 등에 공개한다 [L1-18, L1-20].

### L2 KT 사업

- '모두의 AI' 컨소시엄 참여사에 다음·무신사·직방·EBS·매스프레소·BC카드 등, 접점 합산 6천만 이상, 다음·지니TV 적용 계획, 동의 기반 개인화 메모리(보도) [L2-02].
- 자녀 학습 예시(과학 개념 설명 + EBS·콴다 콘텐츠 추천 + 3D 시각화)는 발표 시나리오이며 출시 기능 확인은 아니다 [L2-03].
- 베타는 일상 질문 응답 우선, 12월 교육 등 외부 서비스 연계 확대 계획(2026-10-07 보도) [L2-04]. 실제 베타 출시 여부는 확인되지 않음.
- 기업용 에이전틱 플랫폼 'Agentic On'은 '모두의 AI'와 별개 제품으로 보도됐다 [L2-07].
- 과거 키즈·교육 사례(기가지니 키즈 콘텐츠, 대교 소리동화)는 구형 기사이며 현재 운영 상태는 확인되지 않음 [L2-09].

### L3 시장·경쟁·유사 서비스

- 2025년 사교육비 총액 27조5000억원(전년 대비 5.7% 감소), 참여율 75.7%(4.3%p 감소), 주당 7.1시간 [L3-09].
