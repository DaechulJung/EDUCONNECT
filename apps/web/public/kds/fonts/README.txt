글꼴 폴더 안내

web/
  코드(웹 화면)용 글꼴입니다.
  키트의 CSS가 자동으로 불러오므로 설치하지 않아도 됩니다.
  파일 이름이나 위치를 바꾸면 글꼴이 깨지니 그대로 두세요.

install-for-figma/
  피그마용 설치 파일입니다.
  피그마는 내 컴퓨터에 설치된 글꼴만 읽으므로 13개를 모두 설치하세요.
  - 맥: 파일 전부 선택 → 더블클릭 → 서체 설치
  - 윈도우: 파일 전부 선택 → 오른쪽 클릭 → 설치
  설치 후 피그마를 껐다 켜야 인식됩니다.

KT Flow는 해커톤 참가자에게만 허락된 서체입니다.
외부 공유, 공개 깃허브 업로드를 하지 마세요.
